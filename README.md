## Projects

- **[Hook Lab](https://fardinraafi.com/projects/hook-lab)** - scores your first line for scroll-stopping power, with rewrites and 38 hook formulas
- **[Swipe the Hook](https://fardinraafi.com/projects/swipe-the-hook)** - Tinder-style game, swipe right on good hooks, left on bad ones
- **[Caption Maker](https://fardinraafi.com/projects/caption-maker)** - AI captions and hashtags in 7 styles
- **[My Bookmarks](https://fardinraafi.com/projects/bookmarks)** - 120 free tools I actually use
- **Fifi** - the AI chat assistant on the site, with a coded fallback brain
- **[Fifi Run](https://fardinraafi.com/404)** - a runner game hiding on the 404 page

## Built with

- Plain HTML, CSS and JavaScript, no framework
- Vercel hosting and serverless functions (`/api`) for the AI features
- Groq API for Fifi, Caption Maker and Swipe the Hook
- Web3Forms for the contact form, Calendly for calls
- Fonts: Syne + DM Sans

## Structure

```
index.html, *.html     pages
main.js                shared nav, footer, preloader, lightbox, haptics
style.css              shared styles
fifi.js                Fifi chat assistant
techtext.js            animated page titles
api/                   serverless AI endpoints (key lives in Vercel env vars)
projects/              tools and games
blog/                  blog posts
```
